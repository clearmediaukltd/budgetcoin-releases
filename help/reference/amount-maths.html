    User guide

    Typing amounts and sums

    The decimal point and thousands separators go in for you

    As you type digits into an amount, the last two become the pence (or cents). Type 1, 0, 1 and the box shows 0.01, then 0.10, then 1.01. So 1250 gives £12.50, and you never need to type the point for an everyday amount.

    Thousands are separated as you go, in your budget’s number format: 123456 shows 1,234.56 (or 1.234,56, 1 234,56 or 1’234.56, depending on Settings → General).

    • To put the point somewhere else, type it yourself: 12.5 gives £12.50 and 50. gives £50.00.
    • Backspace removes the last digit: after 1250, it shows 1.25.
    • Pasted amounts are taken as they are.
    • Currencies without pence, like yen, only get the thousands separators: 12345 shows 12,345.
    • When you open an amount to change it, it’s shown with its separators, and typing at the end carries on in the same way.

    This happens while you type at the end of the box, or over an amount you’ve selected. If you add or delete a digit in the middle of an amount, the thousands separators move to fit: deleting a 0 from 2,000,000.00 gives 200,000.00. To type exactly what you press, turn off Format amounts as you type in Settings → Appearance.

    Sums

    Every amount field can add and subtract, so you never need a separate calculator. Each amount in a sum fills in the same way.

    TypeThe box showsGives you
    4520+128045.20+12.80£58.00
    10000-1250100.00-12.50£87.50
    120000+350001,200.00+350.00£1,550.00

    With Format amounts as you type turned off, type the amounts as they’re shown in the middle column.

    Currency symbols and thousands separators are fine to type (£1,234.56). Anything else, such as letters, × or ÷, can’t be typed into an amount box.

    Changing an Assigned amount

    In the budget’s Assigned column, each box works on its own amount: starting with an operator changes that amount instead of replacing it. A reminder appears under the box while you’re typing.

    TypeMeans
    +5000Add £50
    -2000Take away £20
    60000Replace it with £600
    =-500Set it to minus £5

    Number formats

    Use your budget’s number format. In a budget set to 1.234,56, type 12,50. If something could be read two ways (like 12.5 in that format), the app asks you to check rather than guessing.

    Maths is exact: 0.10 + 0.20 is always 0.30.
