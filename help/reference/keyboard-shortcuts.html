    Menu bar (Mac)

    On a Mac, everything in the menu bar at the top of the screen has a button in the app too. The menus have these extra shortcuts:

    ActionMenumacOS
    SettingsBudgetCoin › Settings…⌘,

    Lock the budget (password-protected budgets only)File › Lock Budget⌘L

    Go to all accountsView › All Accounts⌘2

    File › Export… opens the Export settings, and Help › BudgetCoin Help opens this guide. Windows and Linux have no menu bar. Use the buttons and the sidebar instead.

    In the budget

    ActionmacOSWindows and Linux
    Move between cells↑ ↓ ← →↑ ↓ ← →
    First / last cell in the rowHome / EndHome / End
    First / last row⌘↑ / ⌘↓Ctrl+↑ / Ctrl+↓
    Start editing an amountEnter, F2, or type a numberEnter, F2, or type a number
    Save the amount you’re typingEnterEnter
    Save the amount and go to the category below / above↓ / ↑↓ / ↑
    Save the amount and go to the next / previous cellTab / Shift+TabTab / Shift+Tab
    Cancel editingEscEsc
    Move the selected category or group up / down⌥↑ / ⌥↓Alt+↑ / Alt+↓
    Collapse or expand every group⌥-click a group’s arrowAlt-click a group’s arrow

    The arrow keys move between amounts, category names and group rows, like a spreadsheet. To start somewhere, click a cell, such as an Available amount or a group’s totals. Going up or down past a group row keeps you in the same column. On a group row, press Enter on its arrow to collapse or expand it, or on its name to rename it.

    To budget down a list, select the first Assigned amount, type the amount and press Enter. It’s saved, and the next category’s amount is selected, ready for the next one. Start with + or - to add to or take from the amount already there. An empty amount counts as 0. Clicking away also saves what you typed.

    Tab moves out of the budget in one press, to the rest of the app.

    In an account

    ActionmacOSWindows and Linux
    Go to the new-transaction row⌘NCtrl+N
    Search transactions⌘FCtrl+F
    Move between transactions↑ ↓↑ ↓
    Edit the transactionEnterEnter
    Save the transactionEnterEnter
    Cancel editingEscEsc

    Select a transaction (or press Enter on it) to edit it where it is. Tab moves between its fields, and Enter saves from any of them, including the Category list. In the Payee box, Tab first completes the payee’s name (see Entering transactions). Home and End jump to the newest and oldest transactions. In the search box, Esc clears the search.
