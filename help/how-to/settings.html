    User guide

    Budget settings and passwords

    Choose Settings at the bottom of the sidebar. Settings is split into sections, listed down the left: General, Security, Licence, Payees, Exchange rates, Export and backup, Appearance and Updates. Choose one to show it. In a narrow window the list becomes a Section dropdown. Settings opens on the section you last used.

    General

    • Budget name: shown in the sidebar and window title. The file on disk keeps its original name. The new name is saved when you leave the field or press Enter; Esc puts the old name back.
    • Date format and Number format: how dates and amounts are shown and typed. Changing them doesn’t change any amounts.

    Changes save as soon as you make them. Undo (⌘Z on a Mac, Ctrl+Z on Windows and Linux) reverses a settings change, like any other edit.

    Below these you can see the budget’s currency (chosen when you created it) and where its file is.

    Delete this budget

    Delete budget… at the bottom of General moves this budget to the Trash and closes it, after you type its name (and its password, if it has one). See Delete a budget.

    Security: passwords and auto-lock

    A password encrypts the whole budget file. Without the password or the recovery key, nobody can open it, including us.

    • Add a password (budgets without one): type it twice. You’ll then see a recovery key. Copy it and keep it somewhere safe, such as a password manager or a printed copy in a drawer.
    • Change password: enter your current password and the new one twice. Your recovery key keeps working.
    • New recovery key: makes a new key and shows it once. The old key stops working, so replace any copy you kept.
    • Lock now: saves and closes the budget straight away.
    • Remove password: the file is no longer encrypted. Anyone with the file can read it.

    Password changes are saved to the file immediately and can’t be undone.

    Auto-lock: for a budget with a password, lock it after this many minutes without using the app. When it locks, the budget is saved and closed, and you’ll need the password (or recovery key) to open it again. It saves as soon as you pick it, and undo (⌘Z / Ctrl+Z) reverses it.

    Forgot your password?

    On the unlock screen, choose Use my recovery key instead and type the key. Then go to Settings → Security → Change password: you won’t be asked for the old password, so you can set a new one.

    If you’ve lost both the password and the recovery key, the budget can’t be opened. There is no back door.

    Payees

    Rename, hide, delete and merge payees. See Managing payees.

    Exchange rates

    If some accounts are in other currencies, the app can keep their exchange rates current from the European Central Bank’s daily reference rates. Tick Update exchange rates when this budget opens to fetch them once a day, or choose Update rates now. Each currency’s rates are listed below, where you can also enter your own. See Accounts in other currencies.

    Export and backup

    Save the whole budget as one file, or transactions and budget figures as CSV. See Exporting and backing up.

    Appearance

    Theme sets light or dark colours: Match my computer (the default, which follows your system’s light/dark setting), Light or Dark. It’s a setting for this computer and applies to every budget and the Welcome screen.

    Format amounts as you type (on unless you turn it off) fills in amounts from the right and adds thousands separators as you type, so 123456 gives 1,234.56. Turn it off to type exactly what you press. It’s also a setting for this computer. See Typing amounts and sums.

    Updates

    Shows which version you have, turns the daily check for a newer version on or off, and has Check now. See Updating BudgetCoin.
