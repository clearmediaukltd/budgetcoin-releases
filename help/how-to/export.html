    User guide

    Exporting and backing up

    You can always get your data out. Export budget saves your whole budget in one plain-text file that you can keep as a backup, move to another computer, or read with your own tools.

    Export your whole budget

    1. Open the budget and go to Settings → Export and backup.
    2. Choose Export budget….
    3. Pick a folder and file name, then save.

    The file has everything in the budget: accounts, transactions (including splits and transfers), categories, assigned amounts, payees, flags, exchange rates and your budget’s settings. Undo history isn’t included, so a budget imported from the file starts with nothing to undo.

    The export is written in one go: if something goes wrong part-way, any file that was already there is left as it was.

    Password-protected budgets: the exported file is not encrypted, even if your budget has a password. Anyone who can open the file can read your finances, so store it somewhere safe. To keep an encrypted backup, copy the budget file itself instead.

    Export to a spreadsheet (CSV)

    In Settings → Export and backup → CSV for spreadsheets:

    • Transactions: every account or one account, for all dates or a period such as Last month or This year. Each line of a split transaction gets its own row (the Split column shows 1/2, 2/2 and so on). If any of the exported accounts is in another currency, two extra columns give each amount in your budget’s currency.
    • Budget: assigned, activity and available for every category, one row per category per month, for a range of months.

    Amounts are plain numbers (no currency symbol or thousands separator) with the currency in its own column, so spreadsheets can add them up. Choose:

    • Separator: comma, semicolon or tab. If your spreadsheet expects a comma as the decimal separator, use semicolon.
    • Date format: ISO (2026-11-14, which every spreadsheet understands) or your budget’s own format.
    • For Excel on Windows: tick this if accented letters come out garbled when you open the file in Excel.

    To export just some transactions (say, one payee or one month), search or filter a register and choose Export to CSV in its search row. See Searching and filtering.

    Text that a spreadsheet might treat as a formula (starting with =, +, - or @) gets an apostrophe in front, so opening the file can never run anything.

    Import an exported budget

    1. On the start screen, choose Import an exported budget….
    2. Pick the exported file.

    This creates a new budget in your budgets folder, named after the exported budget, and opens it. It never changes an existing budget. If a budget with that name already exists, a number is added, for example Home (2). The new budget has no password; you can add one in Settings.

    A file from an older version of the app imports normally and is brought up to date. A file from a newer version can’t be imported until you update the app.

    If the file has been edited and no longer makes sense (for example, a transaction refers to an account that isn’t there), nothing is imported and you’ll see what was wrong.

    For the technically curious

    The file is UTF-8 JSON. It lists each table of the budget with its rows; amounts are whole numbers of the currency’s smallest unit (pence, cents) and dates are YYYY-MM-DD. Exporting the same budget twice gives an identical file, so exports work well with version control or file comparison tools.
