Privacidad

Política de privacidad

Última actualización: 23 de noviembre de 2026

Esta política explica qué datos recogen la aplicación BudgetCoin y esta web, y para qué.

La aplicación

Tus presupuestos se guardan como archivos en tu ordenador. La aplicación no envía tus datos de presupuesto ni a nosotros ni a nadie más.

Se conecta a internet para dos cosas, y ambas se pueden desactivar en Ajustes:

  • Tipos de cambio, si tienes cuentas en otras monedas: descarga el archivo público de tipos del Banco Central Europeo.
  • Comprobación de actualizaciones, una vez al día: lee el último número de versión en getbudgetcoin.com.

Estas solicitudes no contienen datos de presupuesto ni datos personales. El servidor que las recibe ve lo que muestra cualquier conexión a internet, como tu dirección IP.

No hay analítica, telemetría ni informes de errores. Tu licencia se comprueba en tu ordenador, sin contactar con nosotros.

Esta web

Esta web no usa cookies, analítica ni seguimiento.

Si eliges un idioma en el menú, tu elección se guarda en tu navegador para que la web la recuerde. La guía de uso guarda su tema claro u oscuro del mismo modo. Estos ajustes se quedan en tu navegador.

La web está alojada en GitHub Pages. GitHub registra las direcciones IP de los visitantes para prestar y proteger el servicio, como se describe en la GitHub Privacy Statement

Cuando compras una licencia

Los pagos los gestiona Stripe, que recoge los datos de tu tarjeta, tu nombre, tu correo y tu dirección de facturación. Nosotros no vemos los datos de tu tarjeta. La página de pago de Stripe usa sus propias cookies, por ejemplo para prevenir fraudes. El uso que Stripe hace de tus datos se rige por la Stripe Privacy Policy

Stripe nos envía tu nombre, tu correo, tu país y los datos del pedido. Los usamos para enviarte tu clave de licencia, reenviarla si la pierdes, responder a tus preguntas y para nuestros registros fiscales y contables.

Tu clave de licencia contiene tu nombre, tu número de pedido y un código irreversible generado a partir de tu correo, para que se sepa a quién se emitió.

Cuando nos escribes

Usamos tu mensaje y tu correo para responderte. El formulario de contacto funciona con Formspree, que recibe lo que envías y nos lo reenvía por correo.

Con quién los compartimos

Solo con los servicios que hacen el trabajo descrito aquí: Stripe para los pagos, Formspree para el formulario de contacto y el servicio de correo con el que enviamos claves de licencia y respuestas.

Cuánto tiempo los guardamos

Los registros de compra se guardan el tiempo que exige la ley fiscal, normalmente seis años. Los demás mensajes se borran cuando ya no hacen falta.

Tus derechos

Puedes pedir una copia de los datos personales que tenemos sobre ti, pedir que los corrijamos o que los borremos, salvo que debamos conservarlos por motivos fiscales. Según dónde vivas, también puedes reclamar ante tu autoridad de protección de datos.

Cambios

Si cambiamos lo que recogen la aplicación o esta web, actualizaremos esta página y la fecha de arriba antes del cambio.
