Confidentialité

Politique de confidentialité

Dernière mise à jour : 24 novembre 2026

Cette politique explique quelles données l'application BudgetCoin et ce site collectent, et pourquoi.

L'application

Vos budgets sont enregistrés sous forme de fichiers sur votre ordinateur. L'application n'envoie vos données de budget ni à nous ni à personne d'autre.

Elle se connecte à Internet pour deux choses, toutes deux désactivables dans les Réglages :

  • Cours de change, si vous avez des comptes dans d'autres devises : elle télécharge le fichier public des cours de la Banque centrale européenne.
  • Vérification des mises à jour, une fois par jour : elle lit le dernier numéro de version sur getbudgetcoin.com.

Ces requêtes ne contiennent aucune donnée de budget ni aucune information personnelle. Le serveur qui les reçoit voit ce que montre toute connexion Internet, comme votre adresse IP.

Il n'y a ni statistiques, ni télémétrie, ni rapports de plantage. Votre licence est vérifiée sur votre ordinateur, sans nous contacter.

Ce site

Ce site n'utilise ni cookies, ni statistiques, ni suivi.

Si vous choisissez une langue dans le menu, votre choix est enregistré dans votre navigateur pour que le site s'en souvienne. Le guide d'utilisation enregistre son thème clair ou sombre de la même façon. Ces réglages restent dans votre navigateur.

Le site est hébergé sur GitHub Pages. GitHub enregistre les adresses IP des visiteurs pour faire fonctionner et protéger le service, comme décrit dans le GitHub Privacy Statement

Quand vous achetez une licence

Les paiements sont gérés par Stripe, qui collecte vos données de carte, votre nom, votre adresse e-mail et votre adresse de facturation. Nous ne voyons pas vos données de carte. La page de paiement de Stripe utilise ses propres cookies, par exemple contre la fraude. L'utilisation de vos données par Stripe est régie par la Stripe Privacy Policy

Stripe nous transmet votre nom, votre adresse e-mail, votre pays et les détails de la commande. Nous les utilisons pour vous envoyer votre clé de licence, la renvoyer si vous la perdez, répondre à vos questions et pour nos obligations fiscales et comptables.

Votre clé de licence contient votre nom, votre numéro de commande et un code irréversible calculé à partir de votre adresse e-mail, pour indiquer à qui elle a été délivrée.

Quand vous nous contactez

Nous utilisons votre message et votre adresse e-mail pour vous répondre. Le formulaire de contact est géré par Formspree, qui reçoit ce que vous envoyez et nous le transmet par e-mail.

Avec qui nous les partageons

Uniquement avec les services qui effectuent le travail décrit ici : Stripe pour les paiements, Formspree pour le formulaire de contact, et le service d'e-mail qui envoie les clés de licence et nos réponses.

Durée de conservation

Les justificatifs d'achat sont conservés aussi longtemps que la loi fiscale l'exige, en général six ans. Les autres messages sont supprimés quand ils ne sont plus utiles.

Vos droits

Vous pouvez demander une copie des données personnelles que nous détenons sur vous, leur rectification ou leur suppression, sauf si nous devons les conserver pour nos obligations fiscales. Selon votre lieu de résidence, vous pouvez aussi déposer une plainte auprès de votre autorité de protection des données.

Modifications

Si nous changeons ce que l'application ou ce site collecte, nous mettrons à jour cette page et la date en haut avant le changement.
